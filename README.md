# Federation Dreadnoughts - MV port
Port of the [Federation Dreadnoughts](https://www.subsetgames.com/forum/viewtopic.php?t=32284) mod, for use with [FTL: Multiverse](https://github.com/FTL-Multiverse-Team/FTL-Multiverse-Releases).  
## Usage
Clone the repo, then zip it up with a program like 7zip. Load using [ftlman](https://github.com/afishhh/ftlman). Place near the bottom of the list, but before any mods that add systems.
